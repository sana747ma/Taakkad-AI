# تأكّد AI (Ta'akkad AI) — منظومة الحماية الذكية من الاحتيال الرقمي

نموذج أولي عامل (**Working MVP**) مطوّر ضمن هاكاثون **SCAMSHIELD AI** (بالتعاون بين شرطة أبوظبي وأكاديمية 42 أبوظبي — نوفمبر 2026)، يهدف إلى حماية المجتمع من الرسائل والروابط والمكالمات الاحتيالية بأسلوب عملي يراعي الخصوصية وسهولة الاستخدام لكافة الفئات، بما في ذلك كبار السن.

---

## الميزات الأساسية للمنصة

1. **فحص الرسائل والروابط مع حماية الخصوصية محلياً (`Local Data Masking`):**
   * تحليل فوري للنصوص والروابط المشبوهة مع مؤشر خطورة ونسبة مئوية وتصنيف واضح (منخفضة / متوسطة / عالية الخطورة).
   * رصد الروابط غير المشفرة (`http://`)، النطاقات المشبوهة أو المختصرة، محاولات انتحال الجهات الرسمية خارج النطاق المعتمد (`.gov.ae`)، وأساليب الاستعجال أو طلب رمز التحقق (`OTP`) وبيانات البطاقات.
   * تعمية وإخفاء البيانات الحساسة (مثل أرقام البطاقات والهويات والهواتف) محلياً داخل متصفح المستخدم قبل عرض المعالجة.

2. **فحص الأرقام الغريبة وسلوك المكالمات (`Vishing & Caller Checker`):**
   * تقييم الأرقام الواردة والمكالمات الدولية المرتبطة بادعاء صفة رسمية أو طلب بيانات حساسة.
   * تحليل سلوك المتصل (طلب `OTP`، ادعاء تحديث الهوية، التهديد بإيقاف الحساب، أو العروض المشبوهة) مع حفظ البلاغات في سجل محلي بالمتصفح وإمكانية إضافة بلاغ جديد.

3. **محاكي التدريب التفاعلي («اختبر مناعتك الرقمية»):**
   * سيناريوهات تفاعلية تحاكي مواقف احتيال واقعية لتدريب المستخدم على اكتشاف الخدع قبل الوقوع فيها، مع احتساب **نقاط المناعة** وتوضيح سبب كل مؤشر خطر.

4. **وضع كبار السن، الدرع العائلي، وبروتوكول الطوارئ:**
   * **وضع كبار السن:** تكبير الخط وتفعيل قراءة صوتية عربية مبسطة (`SpeechSynthesis`) لتوضيح النتائج بوضوح.
   * **الدرع العائلي:** توليد ونسخ أو مشاركة بطاقة تحذير مبسطة عبر واتساب لتنبيه العائلة وكبار السن.
   * **بروتوكول الطوارئ:** خطوات عملية سريعة لأول 5 دقائق في حال الضغط على رابط مشبوه أو مشاركة بيانات، مع روابط مباشرة لقنوات الإبلاغ والتوعية الرسمية في دولة الإمارات.
